## 🇫🇷 Français

# FreshApp Links

Listes de liens configurables, affichables sur un ou plusieurs emplacements du thème.

- **Nom technique** : `freshapplinks`
- **Version** : 1.1.6
- **Auteur** : FreshApp.io
- **Compatibilité** : PrestaShop 1.7 à 9
- **Onglet BO** : `AdminFreshapplinks`, sous *Apparence*

### Fonctionnement

Une liste regroupe des liens vers un produit, une catégorie, une page CMS ou une URL libre.
Chaque liste choisit ses emplacements d'affichage (haut de page, barres de navigation,
bannière, pied de page…), sa disposition (colonne ou ligne) et l'affichage de son titre.
Chaque lien peut porter une icône et son propre style (couleur, police, graisse, casse).

### Icônes

Les icônes sont embarquées dans le module (`views/img/icons/icons.svg`, jeu Lucide sous
licence ISC) : elles s'affichent quel que soit le thème. Une image téléversée peut aussi
servir d'icône.

### Tables

| Table | Rôle |
|---|---|
| `PREFIX_freshapplinks_list` / `_lang` | Listes, emplacements, disposition |
| `PREFIX_freshapplinks_link` / `_lang` | Liens, cible, icône, style |

Retrouvez nos modules sur **[shop.freshapp.io](https://shop.freshapp.io)**.

## 🇬🇧 English

# FreshApp Links

Configurable link lists, displayable on one or several theme positions.

- **Technical name**: `freshapplinks`
- **Version**: 1.1.6
- **Author**: FreshApp.io
- **Compatibility**: PrestaShop 1.7 to 9
- **Back-office tab**: `AdminFreshapplinks`, under *Appearance*

### How it works

A list groups links to a product, a category, a CMS page or a free URL. Each list chooses
its own display positions (page top, navigation bars, banner, footer…), its layout (column or
row) and whether its title is shown. Each link can carry an icon and its own style (colour,
font, weight, case).

### Icons

Icons are bundled with the module (`views/img/icons/icons.svg`, Lucide set under the ISC
licence): they display regardless of the theme in use. An uploaded image can also be used as
an icon.

### Database tables

| Table | Purpose |
|---|---|
| `PREFIX_freshapplinks_list` / `_lang` | Lists, positions, layout |
| `PREFIX_freshapplinks_link` / `_lang` | Links, target, icon, style |

Find our modules on **[shop.freshapp.io](https://shop.freshapp.io)**.
