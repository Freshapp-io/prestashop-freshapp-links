Guide d'installation · version 1.1.2

Installer le module

  1. Dans le back-office, ouvrez Modules > Gestionnaire de modules.
  2. Cliquez sur Installer un module, en haut à droite de l'écran.
  3. Faites glisser dans la zone prévue le fichier .zip que vous avez téléchargé après votre achat, sans le décompresser.
  4. Attendez la fin de l'installation, puis cliquez sur Configurer.
Vous retrouverez ensuite l'écran à tout moment depuis le bouton Configurer du gestionnaire de modules.

Après l'installation

Créez une liste de liens, cochez les emplacements du thème où l'afficher, puis ajoutez ses liens (URL, produit, catégorie ou page CMS). L'interrupteur en haut de l'écran ajoute le module au menu Modules.
