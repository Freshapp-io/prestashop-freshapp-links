# Changelog — FreshApp Links

Une section par version, la plus récente en haut. Chaque puce est une ligne autonome,
formulée côté marchand : le bloc d'une version se colle tel quel dans le champ
« changelog » de freshappprestadownload (une ligne par changement, sans le tiret).

## 1.1.0 — 2026-09-17

- Le module devient FreshApp Links.
- Compatibilité étendue de PrestaShop 1.7 à PrestaShop 9.
- Icônes embarquées dans le module : elles s'affichent quel que soit le thème.

## 1.0.4 — 2026-08-10

- Améliorations de l'interface d'administration.
- Correction de divers bugs.

## 1.0.3 — 2026-07-27

- Nouveau : option pour afficher ou masquer le titre de chaque liste.

## 1.0.2 — 2026-07-20

- Nouveau : disposition des liens en colonne ou en ligne.

## 1.0.1 — 2026-07-16

- Nouveaux emplacements d'affichage : haut de page, barres de navigation, bannière, début et fin de page.

## 1.0.0 — 2026-06-30

- Première version : listes de liens vers un produit, une catégorie, une page CMS ou une URL libre.
- Icône et style personnalisables par lien.
